# YOLO Data v0.1.0

发布日期：2026-10-15

## 版本概览

YOLO Data v0.1.0 是面向企业经营分析的智能问数平台首个可用版本。平台将大模型、智能体、业务数据集、指标语义、权限、Skills、会话记忆和工作区产物整合为一条可追踪的分析链路，帮助业务人员用自然语言完成查询、对比、归因和结果复核。

本版本支持两种主要运行方式：

- **业务数据集直连模式**：不依赖第三方指标平台，直接基于已配置的数据集完成字段语义解析、只读查询和结果分析。
- **指标平台集成模式**：可选接入外部指标平台，用于指标目录、指标口径和指标查询。

未配置第三方指标平台时，平台默认按本地/直连模式运行，不再将“指标平台未配置”判定为降级状态。

## 核心能力

### 1. 自然语言智能问数

- 支持按业务主题切换智能体。
- 支持时间范围、同比/环比、排名、占比、筛选、分组和多轮追问。
- 查询过程按“语义解析、计划、校验、执行、分析、验证、回答”分阶段记录。
- 最终回答支持自然语言总结、重点加粗、结构化表格和图表展示。
- 查询结果可复用，减少重复取数造成的结果漂移。

### 2. 智能体管理

- 每个智能体可独立配置：
  - 指标范围和业务数据集范围；
  - 默认模型及可用模型；
  - 主题提示词；
  - 可用 Skills；
  - 默认图表和业务口径。
- 支持管理员创建、编辑、启停和删除智能体。
- 普通分析员仅看到已授权的智能体。

### 3. 统一模型管理

- 支持 DeepSeek 和 OpenAI Compatible 服务。
- 支持 Base URL、模型标识、API Key、温度、最大工具轮次和超时时间配置。
- 支持平台默认模型和智能体级模型绑定。
- 支持在编辑模型时直接测试连通性。
- API Key 支持环境变量和模型独立密钥两种来源。

### 4. 公共 Skills

- 支持管理员维护平台级公共 Skills 资产池。
- 支持上传 `SKILL.md` 文件、启用/停用、删除和查看引用关系。
- 支持标准 Skill 目录扫描。
- 支持在智能体页签中选择当前智能体使用的 Skills。
- Skills 可参与规划前审计、查询约束和结果验证。

### 5. 业务数据集

- 支持 MySQL、TiDB、Doris，以及可选的 PostgreSQL 数据源。
- 支持数据源连接测试、字段同步、抽样和字段语义配置。
- 支持智能识别时间字段、指标字段、维度字段和默认时间窗口。
- 查询只使用平台生成的只读查询契约，不向模型暴露原始 SQL。

### 6. 权限与治理

- 支持主题级、指标级和数据集级授权。
- 支持行级数据权限。
- 支持列级隐藏和脱敏。
- 支持查询计划、执行过程、模型调用、反馈和结果产物审计。

### 7. 会话记忆与工作区

- 会话按用户和智能体隔离。
- 支持长期记忆摘要、正文、笔记和版本快照。
- 支持查询结果、CSV、JSON、XLSX 和代码执行结果保存为工作区产物。
- 支持继续加工、结果复用和产物追踪。

### 8. 管理控制台体验

- 左侧菜单包含开始问数、指标管理、智能体、数据集、权限、质量运营、运行审计、系统设置和帮助中心。
- “公共 Skills”已合并到“智能体”内部页签。
- 支持响应式布局和移动端适配。
- 开始问数输入区支持全宽布局、圆形发送/中断按钮和附件上传。
- 使用 YOLO 02-B 渐变图形 Logo。

## 部署与启动

### 运行要求

- Node.js `>= 22.5`
- npm 或 pnpm
- 可选 Python 3（代码执行和部分文件分析能力）
- 可选 MySQL/TiDB/Doris/PostgreSQL 数据源
- 可选外部指标平台

### 首次启动

```powershell
cd D:\workspace\metric-ask-platform
npm install
npm run setup
```

按需编辑 `yolo-conf.yaml`，至少配置模型服务：

```yaml
models:
  apiKey: your-api-key
```

启动服务：

```powershell
npm start
```

开发模式：

```powershell
npm run dev
```

默认访问地址：

```text
http://localhost:8088/
```

默认开发账号：

| 用户名 | 角色 | 默认密码 |
| --- | --- | --- |
| `admin` | 平台管理员 | `yolo123456` |
| `east_manager` | 分析员 | `yolo123456` |
| `channel_analyst` | 分析员 | `yolo123456` |

首次登录后应立即修改默认密码，并在生产环境启用会话认证。

## 兼容性与配置说明

- 未配置第三方指标平台时，平台仍可使用本地指标和业务数据集完成问数。
- 未配置大模型 API Key 时，服务可以启动，但会使用本地规则运行模式，回答能力会受到限制。
- 模型配置中的 API Key 不会在页面回显。
- 数据源密码、模型独立密钥和主题密钥采用加密存储。
- 生产环境建议设置 `NODE_ENV=production` 并启用 `AUTH_MODE=session`。

## 已知边界

- 指标平台集成能力依赖外部服务的可用性和权限。
- 高级文件分析和 XLSX 生成依赖 Python 及对应的 `pandas`、`openpyxl` 环境。
- Skills 上传内容需要符合平台支持的 `SKILL.md` 格式。
- 本版本仍属于首个可用版本，生产环境上线前建议补充企业 SSO、密钥托管、备份策略和容量监控。
