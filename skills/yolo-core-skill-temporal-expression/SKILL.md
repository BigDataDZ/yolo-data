# 时间表达式解析

将“昨天”“近 7 天”“本月”“2026 年 8 月”等自然语言时间表达转换为结构化的日期范围。

该 Skill 的执行器由平台内置 resolver 提供。此文档用于声明能力、说明口径和支持热更新，不执行文档中的代码。
